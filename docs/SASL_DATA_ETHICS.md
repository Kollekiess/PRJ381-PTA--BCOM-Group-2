# SASL data and teaching safeguards

SASL is a language, not a collection of interchangeable hand shapes. Meaning can depend on movement, orientation, location, two-hand coordination, facial expression, and context. A fingerspelling classifier is therefore not a general SASL translator.

Before training production lessons:

1. Ask a qualified SASL practitioner or Deaf-community partner to select and demonstrate the lesson content.
2. Obtain explicit consent for every captured sample and document allowed uses, retention, and withdrawal.
3. Split evaluation by signer, not random frame, so the test measures generalization to new people.
4. Include different hand sizes, skin tones, dominant hands, movement styles, and regional variants.
5. Keep a human-readable source and review record for every label.
6. Report per-sign accuracy and confusion, not only a single overall percentage.
7. Never silently replace SASL with ASL data.

The local MVP stores no camera frames and does not upload live joint coordinates. The trainer requires reviewed labels and provenance fields before it will produce a model.
